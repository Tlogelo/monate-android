# Google single sign-on setup

The **Continue with Google** button works once the app has a Google *Web client ID*. This is a one-time setup
by the team, because the ID belongs to a Google Cloud project and cannot be generated by the code.

1. Go to <https://console.cloud.google.com> and create (or pick) a project.
2. **APIs & Services > OAuth consent screen**: choose *External*, fill in the app name and your email, and add your team's
   Google accounts under *Test users* while the app is in testing.
3. **APIs & Services > Credentials > Create credentials > OAuth client ID**, twice:
   - **Web application**: copy its *Client ID*. This is the one the app needs.
   - **Android**: package name `com.example.monatechickensteak` and the **SHA-1** of the key that signs the app.
     For the debug build run `./gradlew signingReport` and copy the SHA-1 of the `debug` variant.
     Every team member who runs the app from their own laptop has a different debug key, so add each SHA-1
     (or share one debug keystore).
4. Paste the Web client ID into `app/src/main/res/values/strings.xml`:

   ```xml
   <string name="google_web_client_id" translatable="false">1234567890-abc.apps.googleusercontent.com</string>
   ```
5. Run on a phone that has a Google account signed in.

## How it works in the app

`GoogleSignInHelper` asks Android's Credential Manager for a Google ID credential. The first sign-in creates a
customer account from the Google name and email (no password is stored, `auth_provider = google`); later sign-ins
reuse it. Google accounts cannot use the password login or "Change password".

## Limitation to mention in the report

The app currently trusts the email returned by the on-device Google credential. A production system with a server
would send the ID token to the backend and verify its signature there before creating a session.

## Troubleshooting

| Message in the app | Cause |
|---|---|
| "Google sign-in is not set up yet" | `google_web_client_id` still has the placeholder |
| "No Google account found on this phone" | add a Google account in the phone's settings |
| "Google sign-in failed" | wrong Web client ID, SHA-1 not registered for this debug key, or no internet |
